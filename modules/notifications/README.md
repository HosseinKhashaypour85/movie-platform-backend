# Notifications Module

ماژول سیستم اعلان‌های درون‌برنامه‌ای کاربران و ارسال پیام‌های دسته‌جمعی ادمین (In-App Notifications & Broadcasts).

## قابلیت‌ها
- نمایش لیست اعلان‌های هر کاربر مرتب‌شده بر اساس تازه‌ترین موارد.
- علامت‌گذاری اعلان به عنوان خوانده‌شده به صورت تکی (`read_at`) یا علامت‌گذاری یکجای تمامی اعلان‌ها (`Mark All Read`).
- **ارسال اعلان همگانی توسط ادمین (Broadcast):**
  - درج دسته‌بندی‌شده و ایمن در دسته‌های ۵۰۰تایی (`CreateInBatches(500)`) برای تمامی کاربران فعال پلتفرم بدون ایجاد بار سنگین روی دیتابیس.
  - پشتیبانی از لینک‌های اکشن (`action_url`) برای هدایت مستقیم کاربر به فیلم، سریال یا رویداد مدنظر.

## اندپوینت‌ها (API Endpoints)
| متد | مسیر | دسترسی | توضیحات |
| :--- | :--- | :--- | :--- |
| `GET` | `/api/v1/notifications` | با توکن | دریافت لیست اعلان‌های کاربر جاری با صفحه‌بندی |
| `PATCH` | `/api/v1/notifications/{id}/read` | با توکن | خوانده شدن یک اعلان مشخص |
| `POST` | `/api/v1/notifications/read-all` | با توکن | خوانده شدن تمام اعلان‌های ثبت‌شده کاربر |
| `POST` | `/api/v1/notifications/broadcast` | مدیر | ارسال اعلان جدید به تمام کاربران فعال سامانه |
