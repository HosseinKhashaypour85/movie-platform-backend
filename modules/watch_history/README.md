# Watch History Module

ماژول ثبت و مدیریت پیشرفت تماشای فیلم‌ها و قسمت‌های سریال توسط کاربران (Watch Progress & Resume Playback).

## قابلیت‌ها
- ثبت دقیق ثانیه فعلی و کل مدت زمان ویدیو برای قابلیت Resume Playback (ادامه تماشا از جایی که متوقف شده).
- تفکیک تاریخچه تماشای فیلم‌ها (`watch_histories`) و قسمت‌های سریال (`episode_watch_histories`).
- تشخیص هوشمند وضعیت اتمام ویدیو (`completed`):
  - برای ویدیوهای بالای ۳۰ ثانیه: در صورتی که کاربر تا ۳۰ ثانیه پایانی ویدیو را تماشا کرده باشد (`progress >= duration - 30`).
  - برای ویدیوهای کوتاه زیر ۳۰ ثانیه (تیزر و کلیپ): در صورتی که حداقل ۹۰٪ ویدیو تماشا شده باشد.
- به‌روزرسانی درجا بدون ایجاد رکوردهای تکراری از طریق کلیدهای ترکیبی منحصربه‌فرد `(user_id, movie_id)` و `(user_id, episode_id)`.

## اندپوینت‌ها (API Endpoints)
| متد | مسیر | دسترسی | توضیحات |
| :--- | :--- | :--- | :--- |
| `GET` | `/api/v1/watch-history` | با توکن | لیست فیلم‌های در حال تماشا یا تماشاشده با صفحه‌بندی |
| `GET` | `/api/v1/watch-history/{movieID}` | با توکن | دریافت وضعیت پیشرفت تماشای یک فیلم خاص |
| `PUT` | `/api/v1/watch-history/{movieID}` | با توکن | ثبت یا به‌روزرسانی پیشرفت تماشای فیلم (`progress_seconds`, `duration_seconds`) |
| `DELETE` | `/api/v1/watch-history/{movieID}` | با توکن | حذف تاریخچه تماشای یک فیلم |
| `GET` | `/api/v1/watch-history/episodes` | با توکن | لیست قسمت‌های سریال در حال تماشا |
| `PUT` | `/api/v1/watch-history/episodes/{episodeID}` | با توکن | ثبت یا به‌روزرسانی پیشرفت تماشای اپیزود |
| `DELETE` | `/api/v1/watch-history/episodes/{episodeID}` | با توکن | حذف تاریخچه تماشای یک اپیزود |
