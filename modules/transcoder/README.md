# Transcoder Module

ماژول پردازش پس‌زمینه و تبدیل فایل‌های ویدیویی به فرمت استریم تطبیقی چندکیفیتی (Adaptive Bitrate HLS Streaming).

## قابلیت‌ها
- ورکر اختصاصی پردازش ویدیو با موتور **ffmpeg**.
- استخراج کیفیت‌های استاندارد متناسب با کیفیت فایل منبع بدون Upscaling:
  - **360p:** بیت‌ریت 800k (بافر 1200k)
  - **480p:** بیت‌ریت 1400k (بافر 2100k)
  - **720p:** بیت‌ریت 2800k (بافر 4200k)
  - **1080p:** بیت‌ریت 5000k (بافر 7500k)
- تولید مانیفست اصلی (`master.m3u8`)، پلی‌لیست‌های اختصاصی هر رزولوشن (`index.m3u8`) و سگمنت‌های ۶ ثانیه‌ای (`.ts`).
- استخراج اطلاعات فنی فایل با `ffprobe` (وضوح، مدت زمان و بررسی وجود ترک صوتی).
- آپلود مستقیم پوشه خروجی HLS به Object Storage و فعال‌سازی رسانه در دیتابیس (`is_active = true`).
- پاکسازی خودکار فایل‌های موقت کاری پس از پایان پردازش.

## ساختار دایرکتوری و اجرا
ورکر ترنسکودر به صورت یک باینری مجزا در مسیر `cmd/transcoder/main.go` اجرا می‌شود:
```bash
go run ./cmd/transcoder
```

## تست‌ها
اجرای تست‌های ماژول ترنسکودر:
```bash
go test -v ./modules/transcoder
```
