# Catalog Module

ماژول مدیریت و نمایش عمومی کاتالوگ فیلم‌ها، سریال‌ها، فصل‌ها و قسمت‌ها.

## قابلیت‌ها
- جستجوی پیشرفته در کاتالوگ فیلم‌ها و سریال‌ها با عنوان فارسی و انگلیسی (`title`, `original_title`).
- فیلتر فیلم‌ها بر اساس ژانر (`genre_id`) و سال تولید (`year`).
- ساختار سلسله‌مراتبی منظم: سریال (Series) ➔ فصل‌ها (Seasons) ➔ قسمت‌ها (Episodes).
- پشتیبانی از حذف نرم (Soft Delete) با فیلد `deleted_at` در GORM.
- لود بهینه اطلاعات مرتبط (مانند ژانرها) با `Preload("Genres")` و عدم آلودگی نشست‌های دیتابیس با `tx.Session(...)`.
- تفکیک کامل محتوای منتشرشده (`is_published = true`) برای کاربران عمومی.

## روابط و مدل‌ها
- **Movie:** فیلم با فیلدهای ریتینگ IMDb، سال ساخت، مدت زمان، پوستر، بک‌دراپ و رابطه چند-به-چند با ژانرها (`movie_genres`).
- **Series:** سریال با سال شروع و پایان، وضعیت انتشار و ژانرها (`series_genres`).
- **Season:** فصل با کلید یکتا مرکب `(series_id, number)`.
- **Episode:** قسمت‌های هر فصل با فیلدهای شماره، عنوان، خلاصه و مدت زمان.

## اندپوینت‌ها (API Endpoints)
| متد | مسیر | دسترسی | توضیحات |
| :--- | :--- | :--- | :--- |
| `GET` | `/api/v1/catalog/movies` | عمومی | لیست فیلم‌ها با فیلتر `q`, `genre_id`, `year`, `limit`, `offset` |
| `GET` | `/api/v1/catalog/movies/{id}` | عمومی | دریافت اطلاعات کامل یک فیلم |
| `GET` | `/api/v1/catalog/series` | عمومی | لیست سریال‌ها با فیلتر جستجو و صفحه‌بندی |
| `GET` | `/api/v1/catalog/series/{id}` | عمومی | دریافت اطلاعات کامل سریال |
| `GET` | `/api/v1/catalog/series/{id}/seasons` | عمومی | لیست فصل‌های یک سریال مرتب‌شده بر اساس شماره فصل |
| `GET` | `/api/v1/catalog/seasons/{id}/episodes` | عمومی | لیست قسمت‌های یک فصل مرتب‌شده بر اساس شماره قسمت |
