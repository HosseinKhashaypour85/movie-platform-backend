# Engagement Module

ماژول تعاملات کاربری شامل سیستم امتیازدهی و لیست علاقه‌مندی‌ها (Ratings & Favorites).

## قابلیت‌ها
- **امتیازدهی به فیلم‌ها:**
  - ثبت یا ویرایش امتیاز کاربر به فیلم در بازه عدد صحیح ۱ تا ۱۰.
  - به‌روزرسانی خودکار بدون ثبت تکراری با مکانیزم Upsert (`ON DUPLICATE KEY UPDATE`).
  - دریافت خلاصه امتیازات شامل میانگین نمرات (`average`) و تعداد کل رأی‌دهندگان (`count`) به صورت عمومی برای بازدیدکنندگان مهمان.
- **لیست علاقه‌مندی‌ها (Favorites):**
  - افزودن فیلم به لیست برگزیده‌ها با تضمین یکتایی برای هر کاربر.
  - دریافت لیست فیلم‌های موردعلاقه با قابلیت صفحه‌بندی (`limit`, `offset`).
  - حذف فیلم از لیست علاقه‌مندی‌ها.

## اندپوینت‌ها (API Endpoints)
| متد | مسیر | دسترسی | توضیحات |
| :--- | :--- | :--- | :--- |
| `GET` | `/api/v1/movies/{movieID}/ratings/summary` | عمومی | دریافت میانگین امتیاز و تعداد آراء فیلم |
| `POST` | `/api/v1/movies/{movieID}/ratings` | با توکن | ثبت یا تغییر امتیاز فیلم (عدد ۱ تا ۱۰) |
| `GET` | `/api/v1/favorites` | با توکن | دریافت لیست فیلم‌های ذخیره‌شده در علاقه‌مندی‌ها |
| `PUT` | `/api/v1/favorites/{movieID}` | با توکن | افزودن فیلم به لیست علاقه‌مندی‌ها |
| `DELETE` | `/api/v1/favorites/{movieID}` | با توکن | حذف فیلم از لیست علاقه‌مندی‌ها |
