# Ads Module

ماژول مدیریت تبلیغات، نمایش هوشمند کمپین‌ها و ردگیری رویدادها (Advertising Campaigns & Event Tracking).

## قابلیت‌ها
- پشتیبانی از فرمت‌های متنوع تبلیغاتی: ویدیویی (`video`)، تصویر (`image`) و بنری (`banner`).
- تعریف اسلات‌های جایگاه تبلیغاتی (`placement`) مانند:
  - `player_pre_roll` (تبلیغ ابتدای پخش ویدیو)
  - `player_mid_roll` (تبلیغ میانه ویدیو)
  - `home_banner` (بنر صفحه اصلی)
- فیلتر خودکار کمپین‌های فعال بر اساس بازه زمانی شروع و پایان (`starts_at`, `ends_at`) و وضعیت فعال بودن (`is_active`).
- ثبت رویدادهای Impression (تعداد نمایش) و Click (کلیک) با تراکنش‌های پایگاه‌داده و به‌روزرسانی آنی شمارنده‌ها.
- پنل مدیریت اختصاصی ادمین برای ایجاد، ویرایش و پایش آمار کمپین‌ها.

## اندپوینت‌ها (API Endpoints)
| متد | مسیر | دسترسی | توضیحات |
| :--- | :--- | :--- | :--- |
| `GET` | `/api/v1/ads` | عمومی | دریافت کمپین‌های فعال متناسب با جایگاه درخواستی (`placement`) |
| `POST` | `/api/v1/ads/{id}/events` | عمومی | ثبت نمایش (`impression`) یا کلیک (`click`) برای کمپین |
| `GET` | `/api/v1/admin/ads` | مدیر | مشاهده تمام کمپین‌های تبلیغاتی و آمار آن‌ها |
| `POST` | `/api/v1/admin/ads` | مدیر | ایجاد کمپین تبلیغاتی جدید |
| `PUT` | `/api/v1/admin/ads/{id}` | مدیر | ویرایش مشخصات یا زمان‌بندی کمپین |
