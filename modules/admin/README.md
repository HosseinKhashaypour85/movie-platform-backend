# Admin Module

ماژول پنل مدیریت سیستم شامل داشبورد آماری، آمار پیشرفته، مانیتورینگ امنیتی (Audit Logs)، مدیریت کاربران، ژانرها و کنترل کامل کاتالوگ.

## قابلیت‌ها
- **امنیت دسترسی:** محافظت‌شده توسط میدلورهای `RequireRole("admin", "super_admin")`.
- **سیستم ثبـت وقایع امنیتی (Audit Middleware):** ثبت خودکار تمامی درخواست‌های تغییردهنده (POST, PUT, PATCH, DELETE) با ضبط شناسه کاربر، IP، هدر X-Request-ID، نوع منبع و کد وضعیت پاسخ.
- **داشبورد و آمار تحلیلی:**
  - شمارش تعداد کاربران، فیلم‌ها، سریال‌ها و اپیزودها با رعایت Soft Delete.
  - گزارش‌های تحلیلی دوره‌ای (۷، ۳۰ و ۹۰ روزه) شامل روند ثبت‌نام، نمودار روزانه بازدیدها و ۱۰ فیلم پربازدید پلتفرم.
- **مدیریت کاربران و دسترسی‌ها:**
  - فعال/غیرفعال کردن حساب‌های کاربری و ابطال آنی نشست‌های حساب‌های غیرفعال‌شده.
  - ارتقا یا تنزیل نقش کاربران (فقط توسط کاربر با نقش `super_admin`).
- **مدیریت ژانرها و محتوا:**
  - کنترل وابستگی‌ها هنگام حذف (عدم امکان حذف ژانر یا سریالی که دارای وابستگی و محتوای فعال است).

## اندپوینت‌ها (API Endpoints)
| متد | مسیر | دسترسی | توضیحات |
| :--- | :--- | :--- | :--- |
| `GET` | `/api/v1/admin/dashboard` | مدیر | آمار کلی موجودیت‌های پلتفرم |
| `GET` | `/api/v1/admin/analytics` | مدیر | تحلیل‌های آماری دوره‌ای با فیلتر `days=7|30|90` |
| `GET` | `/api/v1/admin/audit-logs` | مدیر | لاگ‌های تغییرات و دسترسی‌های مدیران |
| `GET` | `/api/v1/admin/users` | مدیر | لیست کاربران با فیلتر وضعیت و جستجوی نام/ایمیل |
| `PATCH` | `/api/v1/admin/users/{id}/status` | مدیر | فعال یا غیرفعال کردن دسترسی کاربر |
| `PATCH` | `/api/v1/admin/users/{id}/role` | سوپر ادمین | تغییر نقش کاربر به `user`, `admin`, `super_admin` |
| `POST` | `/api/v1/admin/genres` | مدیر | ایجاد ژانر جدید |
| `PUT` | `/api/v1/admin/genres/{id}` | مدیر | ویرایش عنوان یا اسلاگ ژانر |
| `DELETE` | `/api/v1/admin/genres/{id}` | مدیر | حذف ژانر (در صورت عدم تخصیص به فیلم و سریال) |
| `POST` | `/api/v1/admin/movies` | مدیر | ثبت فیلم جدید با جزییات کامل و وضعیت انتشار |
| `PUT` | `/api/v1/admin/movies/{id}` | مدیر | ویرایش اطلاعات فیلم |
| `DELETE` | `/api/v1/admin/movies/{id}` | مدیر | حذف نرم فیلم |
| `POST` | `/api/v1/admin/series` | مدیر | ثبت سریال جدید |
| `PUT` | `/api/v1/admin/series/{id}` | مدیر | ویرایش سریال |
| `DELETE` | `/api/v1/admin/series/{id}` | مدیر | حذف سریال (با کنترل عدم وجود فصل) |
| `POST` | `/api/v1/admin/seasons` | مدیر | تعریف فصل جدید برای سریال |
| `PUT` | `/api/v1/admin/seasons/{id}` | مدیر | ویرایش فصل |
| `DELETE` | `/api/v1/admin/seasons/{id}` | مدیر | حذف فصل (با کنترل عدم وجود اپیزود) |
| `POST` | `/api/v1/admin/episodes` | مدیر | ثبت اپیزود جدید با اطلاعات و مدت زمان |
| `PUT` | `/api/v1/admin/episodes/{id}` | مدیر | ویرایش اپیزود |
| `DELETE` | `/api/v1/admin/episodes/{id}` | مدیر | حذف اپیزود |
